\# Loan Portfolio \& Repayment Analytics Dashboard



An interactive Bank Loan Portfolio \& Credit Risk Analysis Dashboard developed using Microsoft Power BI to analyze loan performance, repayment trends, customer profiles, and portfolio risk.



\## Project Overview

This project analyzes 37K+ loan records with a total loan amount of $422.62M through a five-page interactive Power BI dashboard. It provides insights into loan distribution, repayment performance, customer demographics, and credit risk indicators.



\## Project Highlights

\- Analyzed 37K+ loan records.

\- Evaluated a total loan amount of $422.62M.

\- Developed a 5-page interactive Power BI dashboard.

\- Created custom DAX measures and KPI cards to monitor loan performance.

\- Analyzed loan status, loan purpose, grade/sub-grade, gender, area type, and home ownership.

\- Implemented interactive slicers, drill-downs, maps, tables, and cross-filtering for dynamic analysis.

\- Applied Power Query transformations and Star Schema data modeling.

\## Data Model

The project follows a Star Schema consisting of one central fact table and seven dimension tables:



\*\*Fact Table\*\*

\- `Loans`



\*\*Dimension Tables\*\*

\- `Customer`

\- `Home Ownership`

\- `Loan Purpose`

\- `Grade`

\- `Loan Status`

\- `DateDimension`

\- `Verified Status`



\## Dashboard Analysis

The dashboard covers the following analytical areas:

\- \*\*Loan Portfolio Performance:\*\* Overall loan volume and funded amount analysis.

\- \*\*Loan Status Analysis:\*\* Fully paid, current, and charged-off loan distribution.

\- \*\*Time-Based Analysis:\*\* Loan trends by year and quarter.

\- \*\*Loan Purpose Analysis:\*\* Distribution of loans across different purposes.

\- \*\*Credit Grade Analysis:\*\* Loan performance across grades and sub-grades.

\- \*\*Customer Analysis:\*\* Loan distribution by gender, area type, and home ownership.

\- \*\*Geographic Analysis:\*\* Regional loan distribution and portfolio trends.
